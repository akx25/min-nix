# min-nix
a minimalistic & simple https://github.com/fastfetch-cli/fastfetch type tool designed for NixOS!
## Requirements:
+ Python
+ termcolor
+ psutil
+ colorama
### Links: 
+ Python: https://www.python.org/downloads/
+ termcolor: https://pypi.org/project/termcolor/
+ psutil: https://pypi.org/project/psutil/
+ colorama: https://pypi.org/project/colorama/
## Commands:
+ --help, -h
+ --issue
